## 1. 根因链（每一环都读自线上源码，非推断）

```

    → TRINT_TRANSPORT_REQUEST:76-92      TRINT_EXPORT_ON_OS_LEVEL 的 2/3/4 全部 → export_failed
      → TRINT_EXPORT_ON_OS_LEVEL:42      PERFORM release_by_tp
        → LSCTS_RELEASEF02: FORM release_by_tp
```

回执文本「无法启动传输控制程序 tp」是被调方**自己的消息**（助手用 `sy-msgid/sy-msgno` 组装），因此失败**在 OS 层**，不在任何 CTS 业务判定里。与同族 import 工具**同一根边界**（`TMS_TP_IMPORT` → `calleeSubrc 2` + 同一句文本，`docs/ops-coverage.md` §7.24 D）：**tp 在本系统不可执行**。

## 2. 本批排除的四个候选解释（每个都由证据证伪）

| # | 候选解释 | 证伪证据 |

**方法论记录**：候选 2 的证伪同时暴露一个更重要的教训——**当两个假设对可观测结果给出相同预测时，实验不构成证据**。最终定位靠的是逐环读源码。
