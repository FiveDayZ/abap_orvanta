## 一、本批做了什么

R46 修复了 `UPDATE_HOOK_ENHANCEMENT` 的守卫次序缺陷（在**加锁**句柄上求 `has_inactive_version( )`，而加锁物化的工作副本恒报有非活动版本 ⇒ 守卫无条件拒绝），并指出 `UPDATE_BADI_ENHANCEMENT` 与之**同处一个 `WHEN` 块的两条臂**。本批以**实测**（而非读源码推断）确认该修复确实覆盖 New BAdI 臂，并把工具升格。
