## 剩余风险与优先级

1. `authorizations` 族**仍非闭环**（必需族仍 11/14、`criterionMet` false）：族剩余缺口只有**授权追踪数据**
   （`AUTH_TRACE_GET_AUTHVAL_DATA` 带不可验证类型 `XUBITVEC16` ⇒ 需 SAP 侧助手新分支 + 部署），须用户裁定是否立项。
2. 该工具**不能证明角色是否存在**（`AGR_DEFINE` 未登记读），空答案只是"该名字没有存储取值"——已写进契约与 `notes`。
3. 参数文件通路只覆盖"参数文件→权限对象/子参数文件"（`UST10S`/`UST10C`）；再往下的参数文件值展开不在本工具范围。
4. 既有 `read_user_authorizations` 的文档列了 `USER_AUTHORIZATIONS_NOT_AUTHORIZED`/`_RFC_FAILED`，但评审读取器对
   RFC fault 抛的是**裸名**而既有 mapError 只认前缀形式 ⇒ 这两个码在它那里产不出（会落到 `_QUERY_FAILED`）。
   **本批只报告，未改**（改它等于动一个已 `verified` 工具的错误面）。新工具已显式处理裸名与前缀两种形式。
