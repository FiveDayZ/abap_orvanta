### 3.1 升格口径（重要，不得被读成更强的声明）

本行升 `verified` 所依据的是**孤儿注册清理臂**。**从未观测到单次 `PERMANENT_DELETE` 同时清掉框架数据与 TADIR 行**——这不是本批的偶然：凡经本工具创建的对象都必然落入一个打开的传输任务，因此它自己的 TADIR 清理会被 `OBJECT_LOCKED_FOR_ORDER` 拒绝，直到对象离开该任务为止。完整删除在实践中是**两步**（R46 实测框架删除成功、R48 实测注册行移除成功），两步现在都有真机成功回执 + 独立读回。该限制已写入登记表 notes 与矩阵行，**不**让升格暗示一次调用即可删净。
