## 确认问题及行为变化

1. r38 红测复现：ZodEffects 作为注册输入时，公开 tools/list 缺少比较工具所有参数，3 项测试中 2 项失败。只为该工具拆出输入 object，服务继续在 SAP 调用前执行跨字段规则。公开参数为 from、to、unitKey、language、ignoreFields。
2. 本地适配器原先将创建后的 NRLEVEL 空串当作唯一零值；实际 NRLEVEL 数据元素指向 NUMC20。现统一空值/零/20 位零用于比较，非零状态不会被掩盖。上下界全程保留 20 位字符串，禁止 Number 精度损失。
3. 保存成功必须同时证明完整定义、全部间隔、前后版本、提交、标准会话重置和解锁；同值结果也核对原生返回与实际现值。不完整或提交/IO/清理异常保留 unknown，不自动重试或假称回滚。
4. 标准 NUMBER_RANGE_UPDATE_CLOSE 实际写 NRIV 并登记 NRINTERVAL_WRITE_DOCUMENT 更新任务；提交后的更新任务错误可能形成不确定结果。本阶段不承诺所有更新任务副作用全局原子回滚，不执行取号、缓冲/年度/子对象/分组/已使用间隔保存。
5. r39 源码、接口及 DDIC依据为本次 w200 实际读取。只锁定当前已审查入口及相关 include；标准深层 changedocument / workflow 链的所有后代未逐一做闭包证明，仍须原生诊断和验收。
