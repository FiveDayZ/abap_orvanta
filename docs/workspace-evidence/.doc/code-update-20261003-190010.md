## 一、确认的缺陷根因与修复方法

### 1.1 `UPDATE_HOOK_ENHANCEMENT` 加锁次序缺陷（R17 遗留，本批证实并修复）

**根因（结构性证实，非推测）**：该分支先用
`cl_enh_factory=>get_enhancement( enhancement_id = … lock = 'X' bypassing_buffer = 'X' )`
取句柄，**之后**才在**已加锁**的句柄上求 `li_enh_object->has_inactive_version( )`。加锁会物化一份工作副本，该副本恒报「存在非活动版本」，于是守卫**无条件拒绝**。

**同生成器内两个旁证**证明 `'X'` 的语义是「**存在可用的非活动版本**」：

- `MANAGE_ENHANCEMENT_STATE`：`IF lv_enh_inactive IS INITIAL.` → 返回 `ENHANCEMENT_ALREADY_ACTIVE` / `ENHANCEMENT_NO_INACTIVE_VERSION`；否则继续 `activate()`。即 `'X'` 是**可用的**非活动版本。
- `READ_ENHANCEMENT_IMPL`：**不加锁**取句柄后再求同一标志——这正是「所有读回都报无非活动版本、而所有加锁调用都看到」的原因。

**修复**：改为在**取锁之前**用**独立的未加锁句柄**求该标志；守卫通过后才取加锁句柄。同一处改动同时覆盖 `UPDATE_BADI_ENHANCEMENT`（R18 的 `update_new_badi_implementation` 共用该代码块）。

### 1.2 ENHO 删除遗留 TADIR 注册（R17 残留，本批定位并加固）

框架删除 `IF_ENH_OBJECT->DELETE` 只清框架数据，**遗留 TADIR 行**。本批在助手 `DELETE_ENHANCEMENT_IMPL` 中补上 TADIR 清理，并把结果拆成可分辨的两种：

- 清理后 TADIR 行消失 → `ENHANCEMENT_IMPLEMENTATION_DELETED`（成功），并回报 `TADIR_ENTRY_REMOVED`
- 清理后 TADIR 行仍在 → `ENHANCEMENT_DELETE_PARTIAL`，且**点名真实阻塞者**（新增：具体异常名 + E071 中的订单号）

**实测阻塞者**：`TADIR entry kept: OBJECT_LOCKED_FOR_ORDER GR2K923492`。

**为何本机无自动清理路线（三条实测证据）**：

1. `TR_TADIR_INTERFACE` 委派给 `TRINT_TADIR_INTERFACE`，后者在**删除分支之前**执行 `check_tadir_vs_e071_1`，因订单锁拒绝。
2. 内部的 `TRINT_TADIR_DELETE` 同样经 `TR_CHECK_OBJECT_LOCK` 拒绝，并报出锁定任务。
3. `TFDIR` 全量枚举（`TRINT_*` 418 条、`TR_*` 479 条）**不存在**任何「把对象移出请求」的公开函数模块：`TR_OBJECTS_DELETE` 在 ECC 7.31 SP04 上不存在，只有 `TR_OBJECTS_INSERT` / `TR_OBJECTS_CHECK` / `TRINT_OBJECTS_CHECK_AND_INSERT`。

⇒ 注册行只能在对象离开打开任务后删除，那是 **SE09/SE10 动作**。**用户 2026-10-03 裁定**：由用户在 SE09/SE10 把这四个对象从任务 `GR2K923492` 删除，之后用 `delete_enhancement_implementation` 的 `DELETE_ORPHANED_REGISTRATION` 收尾 TADIR 行。

### 1.3 新增：孤儿注册清理模式（`DELETE_ORPHANED_REGISTRATION`）

为承接 1.2 的收尾，工具新增一个**显式**模式，**双重守卫**：

- 契约层：必须显式传 `confirmation: "DELETE_ORPHANED_REGISTRATION"`，且此时**不得**提供 `expectedFingerprint`（提供则拒 `ENHANCEMENT_ORPHAN_FINGERPRINT_NOT_APPLICABLE`）
- 回执前置观测层（`src/write-prechange-evidence.ts`）：读得到对象即拒 `ENHANCEMENT_ORPHAN_NOT_CONFIRMED`，**写入不发起**
- 助手层：独立地再次确认对象**无法装载**，否则拒 `ENHANCEMENT_ORPHAN_NOT_CONFIRMED`
