本地356/356测试通过，含 `ZTPMC_RKH-ZRKZZ → ZPMCEZZDH → CHAR50` 模拟后端回归。随后候选4848已完成[真实SAP元数据复验](../../.doc/m7-candidate-readonly-review-20260910-113320.md)：详情IV_ZRKZZ为scalar、maxCharacters=50，四个入库计划接口均报告支持，源码及接口指纹与首轮一致。未执行业务调用，不能据此宣称业务验收通过。版本字段仍为0.36.28，原ZIP及旧服务未更新，不能凭版本号断言全局上线。详见[开发记录](../../.doc/code-update-20260910-111728.md)。

## 0.36.3 追加补丁（尚待部署验收）

0.36.2 在 w200 的真实回归仍失败：库存查询报分段长度错误；资源查询已能识别透明表，但两个表存在无数据元素的直接类型字段，仍被拒绝。不得将此前本地通过等同这两项真实验收通过。

- 仓库 SOAP 解析启用现有解析器的数字实体解码；本地测试已用数字实体复现同样的长度错误，并验证解码后源码中的实体字面文本不被二次解码。仍需新版真实回读确认根因闭环。
- DDIC 助手生成器对结构和透明表补充 DATATYPE、LENG、COMPTYPE；客户端仅接受明确的基础类型和有效长度，继续拒绝深层、未知或缺少元数据的字段。本次直接类型白名单为 DATS、TIMS、CHAR、NUMC、INT1、INT2、INT4，不宣称支持全部直接类型。
- 需要另行批准部署 `Z_CODEX_MCP_DDIC_API` 的两个只读载荷输出分支。已只读核对包 ZABAP、请求 GR2K923421，尚未修改该 SAP 对象。
- 当前运行服务仍为 0.36.2；0.36.3 本地补丁不会热更新现有进程。

## 两项修复

1. 函数接口读取：仓库助手的只读分支改用已在 w200 确认存在的 `RPY_FUNCTIONMODULE_READ_NEW`，通过 `NEW_SOURCE` / `RSFB_SOURCE` 接收旧 72 字符缓冲无法容纳的完整源码。
2. RFC 类型解析：`READ_STRUCTURE` 明确返回 `OBJECT_TYPE_MISMATCH` 时，尝试已有 `READ_TRANSPARENT_TABLE` 只读能力，核对同名 TRANSP 对象并沿用平面字段检查。支持直接结构参数、经典 TABLES 和 DDIC 表类型的透明表行类型。

权限、网络和其他错误不触发后备；复杂 Include/Append、无数据元素字段、重复字段及超过 100 字段的既有限制继续保留。

## 长源码传输

- 新客户端在 READ_FUNCTION_INTERFACE 请求中发送 `IV_OBJECT_TYPE=SRC1`，适配现有 4 字符字段。
- 短源码仍使用原 `S|行号|LINE|内容` 格式，保持原指纹。
- 长源码使用 `SOURCE_FORMAT=CHUNKS_V1`、总行数、每行长度和每段最多 60 字符的 PART 序列。每条载荷仍不超过 ABAPTXT255，包括百分号和竖线转义。
- 解码还原边界空格、空行及实体字面文本；重复属性、缺段、总行数不匹配、未知协议和超过 255 字符的行均拒绝。
- 旧客户端请求长源码时助手明确返回 SOURCE_CLIENT_UPGRADE_REQUIRED，不返回截断结果。

新读取能力不等于旧写入 API 已支持长源码。当前函数接口补丁检测到源码行超过 72 字符时，在修改 SAP 前拒绝。不要为了通过检查而格式化或截断业务函数源码。

## 部署顺序

1. 安装 ORVANTA 0.36.2 客户端。保留连接配置、ABAP*MCP*\* 环境变量、原状态与操作凭证目录。
2. 取得准确 SAP 助手对象、包和可修改传输的授权后，更新 `Z_CODEX_MCP_DYNPRO_API` 的只读函数接口分支及配套声明。当前核对的归属为函数组 `ZCODEX_MCP_CORE`、包 `ZABAP`、请求 `GR2K923421`；部署前必须再次核对。
3. 对助手执行源码回读、语法诊断、激活及授权的只读回归。不要释放传输，不修改库存或资源查询业务函数。
4. 回读 `ZPMC_FM_STOCK_QUERY`，核对完整长源码；回读 `ZPMC_TZ_RK_RESOURCE_QUERY` 并指定 includeExecutionSupport=true，核对三个透明表行类型。

源码和便携包构建不会自动升级 SAP 助手，也不会接管或重启用户正在运行的 0.36.1 服务。未完成两端部署和真实回读前，不应宣称实际故障已消失。

## 验收边界

本地测试覆盖 SOAP 解析、长源码、空格/转义、异常载荷、透明表及其表类型、拒绝权限错误和复杂类型、长源码写入前拒绝。SAP 标准读取函数和相关 DDIC 类型已在 w200 只读确认。

# 0.36.31 第一批MVP增量

本节为候选实现，不代表真实SAP验收。两个RFC入口复用活动DDIC的标量及平面字段约束：CHAR类长度、NUMC数字、INT1/2/4范围、DEC/CURR/QUAN精度与小数位。结构字段的完整DD03P元数据优先，缺失时回读数据元素/域；身份不符、缺少元数据和深字段不继续调用。

十进制输入使用字符串，不转JavaScript Number、不静默舍入；允许前导零、正负号及不改变精度的末尾零，不接受分组逗号或指数。空字符串保留为显式初始输入，不在客户端转换为零；字段省略仍沿用现有接口及SAP默认语义。日期、时间、浮点的完整词法及业务域固定值验证不在本批新增范围，不能认为已执行业务校验。输出保留SAP文本，仅应用相应字符长度及结构边界，不按输入十进制词法改写输出。

`executionSupport.parameters`新增可选 `valueContract` / `fieldContracts`，原字段和输入参数名保留。有效元数据现在是字段校验的前提，缺少读取权限时会明确拒绝，不放宽权限。错误信息只包含字段及约束，不回显业务输入。

异常断言改为准确匹配 `fault.name`，不再将错误文本包含期望异常名视为通过。函数接口补丁在SAP原生锁内复核完整ADT源码指纹，保留接口指纹及正文不变检查。四参数方向与经典异常的逐步生命周期回归已准备，人工执行前不记作通过。
