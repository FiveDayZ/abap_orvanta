# Local Icons

Eight unmodified SVG icons from Lucide 0.468.0, downloaded from the official
`lucide-icons/lucide` repository at the `0.468.0` tag. The adjacent `LICENSE`
contains the upstream ISC license and Feather attribution.

`github.svg` is the unmodified `mark-github-24.svg` from GitHub's official
`primer/octicons` repository. Its MIT license is included in
`OCTICONS-LICENSE`.

These static assets are served locally. No CDN or new runtime package is used.

`orvanta-mark.svg` and `orvanta-favicon.svg` are original ORVANTA brand assets.
They are not part of the Lucide set.
